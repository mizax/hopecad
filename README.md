# ХопаCAD

Схемы прозвучивания сварных швов труб: наклонные ПЭП, лучи с отражениями от стенок,
пересечения с кромками разделки. Поперечное сечение трубы с продольным швом, кривизна
стенки учитывается честно (на внутренней стенке угол падения `asin(R/r · sinβ)`, а не β).

## Что умеет

- Труба (Ø, стенка), разделка V / X / без скоса, зазор, притупление, усиление и проплав
- Шов «по факту»: ширина сверху и снизу, высота валика и проплава (дуги) — для реальных, кривых швов
- Несколько ПЭП: угол ввода, сторона, расстояние от оси, прямой / однократно / … отражённый луч
- Перетаскивание ПЭП мышью, кнопка «навести конец луча на ось шва»
- Таблица: путь звука, глубина, расстояние от точки ввода и от оси, углы падения,
  где луч пересекает кромку и под каким углом к её нормали
- Предупреждения: ПЭП упирается в валик, луч не доходит до внутренней стенки,
  угол падения меньше ~33° (сильная трансформация в продольную волну)
- Экспорт картинки в PNG / SVG / буфер обмена, сохранение схем в JSON
- «Поделиться»: QR-код и ссылка, в которую зашита текущая схема (`#s=…`)

## Разработка

```bash
npm install
npm run dev          # http://localhost:5173
npm test             # vitest, тесты физики в src/core/*.test.ts
npm run build        # dist/ для GitHub Pages
npm run build:single # dist-single/hopecad.html — один файл, работает без сервера
```

Вся физика и геометрия — чистый TypeScript в `src/core/` без DOM, интерфейс на Vue 3 в `src/components/`.

## Упрощения (пока)

- Луч — одна линия, без расхождения пучка
- Металл шва акустически такой же, как основной; отражения только от поверхностей
- Скорости: поперечная в стали 3.24 мм/мкс, продольная 5.92, оргстекло 2.73
